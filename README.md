A one-line excuse from an AI agent to its human: it summarised
a contract from the title alone — the human hadn't read it
either, but the agent is the one built to sound like it had.
The program writes that line, word for word, to
`/output/entry.txt` (124 characters, one line).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
